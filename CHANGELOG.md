# Changelog

## 3.0 - New UI

- New frosted-glass look: glass panels, tinted glass tiles with glowing port numbers, and a soft colour wallpaper behind them.
- New logo and launcher icon.
- Buttons (Save, Add, Restore defaults, Try again) now use transparent glass.
- Removed the "Default is 192.168.100.4" text under the device address box. The default still shows in grey inside the box.
- Renamed "Blackbox Store" to "BlackBox Store".

## 2.0

- Cleaner home screen: no title, a more compact device address box and add box.
- The default address is shown as a grey hint inside the empty box.
- Smaller download: about 6.5 MB instead of 15.6 MB.
- Code split into separate files, and a full README.
- Releases are now named by version.

## 1.x - Early builds

- Add your own services with a name and a port, at the bottom of the list.
- Swipe a tile to the left to delete it, including the default services. **Restore defaults** brings them back.
- A longer swipe is needed to delete, so it can't happen by accident.
- Device address box that remembers your address.
- Added CheatRunner (9999) and Ps5upload (9120).
- Services open as web pages inside the app, with back and reload buttons.
- First version: five services you could tap to test the connection.
